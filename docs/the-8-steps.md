# The 8 Steps of the Universal Cycle Framework

## 1. Request
Activation of intent.  
A system becomes aware of a need, goal, question, or trigger.

Mechanically: system activation.  
Examples: user intent, task creation, problem detection.

## 2. Acquisition
Gathering relevant input.  
The system collects information required to proceed.

Mechanically: input retrieval.  
Examples: data collection, listening, scanning, research.

## 3. Holding
Stabilizing and retaining state.  
The system keeps only what is relevant and discards noise.

Mechanically: state retention.  
Examples: memory, focus, prioritization, context storage.

## 4. Center
Selecting a single directional anchor.  
The system chooses a core reference point or objective.

Mechanically: direction selection.  
Examples: strategy, goal selection, central value.

## 5. Progression
Step‑by‑step execution.  
The system moves forward through actions or transformations.

Mechanically: sequential processing.  
Examples: planning, development, iteration.

## 6. Registration
Logging and monitoring.  
The system records what is happening.

Mechanically: state logging.  
Examples: metrics, KPIs, monitoring, evaluation.

## 7. Emergence
Visible output or effect.  
The system produces a result, behavior, or outcome.

Mechanically: output generation.  
Examples: product, decision, performance, behavior.

## 8. Return
Feedback loop and reset.  
The system returns information to the beginning of the cycle.

Mechanically: feedback integration.  
Examples: learning, correction, adaptation, restart.
